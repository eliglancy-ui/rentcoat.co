# Tees on Tapstitch (RU0014)

Each tee has two files, both transparent PNG at 300 DPI:

- `tee-<name>-back.png`: 3600 x 4800 px = 12 x 16 in. Upload to the Back, centered, top about 3 in below the collar.
- `tee-<name>-chest.png`: 3.5 in wide. Upload to the Front on the wearer's LEFT chest (right side of the screen), about 3 in below the collar, center about 3.75 in from the middle.
